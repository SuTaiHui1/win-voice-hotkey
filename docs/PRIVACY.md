# 隐私与系统行为

工具不提供网络客户端、账号、遥测、录音保存或自动更新。Windows Win+H 使用在线语音识别，网络/麦克风/语音设置由 Windows 管理。[Microsoft 说明](https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc)

低层钩子识别绑定所需的键码、扫描码、鼠标键/滚轮、按下/释放及注入标志。录制暂存一个候选；不保存键入字符、完整输入历史或输入框文本。设置打开时暂停映射；鼠标录制只在该窗口自己的录制区进行。

关闭只观察候选语音面板的原生类名、进程/线程、创建时间和可见性，并核验控件标识与 InvokePattern。辅助进程不采集屏幕、音频或编辑文本；不能确认唯一目标就停止。

本地文件包括自选 config.ini、mapping-state.ini（版本、绑定、PID/窗口句柄/实例随机标识及最近关闭状态）、有界 lifecycle.log（启动、就绪、退出和状态发布错误）和短暂代理就绪文件。生命周期日志只含时间、实例和错误元数据，默认独立于可选支持诊断；不保存按键历史、输入文本、音频、前台窗口或截图，不自动上传任何文件。

显式为进程设置 WIN_VOICE_HOTKEY_SUPPORT_DIAGNOSTICS=1 时，可选支持日志记录有限键名、配置路径、时间、候选计数和窗口核验元数据，不含输入文本/音频；日志有大小上限。该模式默认关闭；分享前移除个人路径、PID 和不必要运行数据。不要把整个数据目录打包进公开 issue。

自动测试仅在独立目录产生测试配置、状态和断言。公开源码/发行包排除真实配置、原始日志、备份、凭据、聊天/窗口内容和个人信息。源码包内的测试 fixture 是可读的合成回归输入，不是日常运行数据。
## 0.1.4 中文准备与按需代理

唤醒前仅读取原目标窗口/焦点句柄、进程/线程及输入布局标识，向该目标发送明确的中文输入语言切换请求并确认；不读取文本框文字，不安装语言包、修改系统默认语言或删除输入法。原目标或用户语言选择变化时取消，关闭后不自动恢复旧英文。该行为只作用于本程序唤醒路径。

中文成功、准备、失败和取消均不主动弹通知。LanguageResult、BrokerMode/BrokerPhase/BrokerLastError及必要生命周期事件保留真实结果，静默失败不会记成成功；用户手动查看状态窗口仍可获得诊断。代理按需启动及空闲回收只改变本工具辅助进程的生命周期，不结束Windows语音服务，不持续采集声音，不全局关闭系统通知。

发行文档只含脱敏汇总指标，不含真实PID、用户目录、个人配置、原始日志或本机私有测量报告。Windows Win+H仍可能显示自己的面板/错误，其在线语音和麦克风隐私由Windows管理。
