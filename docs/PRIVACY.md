# 隐私与系统行为

工具本身无网络客户端、账号、遥测、录音保存与自动更新。Windows 的 Win+H 使用在线语音识别，其网络、麦克风、语音和诊断策略由 Windows 管理。[Microsoft 说明](https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc)

低层键盘/鼠标钩子用于识别选定物理键、按下/释放与注入标志。显式录制时暂存一次候选 VK/SC；Shift 组合判定只保留是否出现其他键的布尔状态。不保存键入字符、完整历史或编辑区文本。

关闭动作只跟踪候选系统语音面板的窗口元数据，逐项核验类名、宿主可执行路径、进程创建时间、控件 AutomationId、按钮状态和 InvokePattern。不能确认唯一目标就停止。辅助进程不会采集屏幕、访问麦克风或读取输入文本。

本地数据：`config.ini`（自选绑定）、`mapping-state.ini`（运行 PID、窗口句柄、随机本实例标识、状态与最近关闭结果）、短暂就绪文件（辅助进程就绪信息）。这些都是本地运行数据，不会自动上传。正式程序不保存触发日志或关闭详细窗口报告。不要把数据目录打包进公开 issue。

自动测试会在独立测试输出目录保存断言与临时状态；源码仓库和发行包不包含真实用户测试日志、录音或桌面截图。
