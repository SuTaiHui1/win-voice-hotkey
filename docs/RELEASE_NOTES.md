# v0.1.2 · Windows 语音输入快捷键工具

本版汇总当前日常使用版本的真实关闭、同键切换、键鼠绑定、生命周期/安装停止和设置易用性更新。默认仍为后退侧键打开、前进侧键关闭，不分发个人配置。

- 修复退出互斥锁回调、停止等待与安装器停止门禁；失败/超时不继续改文件。
- 保留真实 CloseButton.Invoke；合并并重验事件候选，补查子框架。同键按真实面板状态切换。
- 支持可捕获的键盘单键、鼠标键及各方向滚轮；紧急暂停、恢复默认和配置回滚。
- 大鼠标录制区、可缩放紧凑布局、分层说明；Esc 先停止录制再退出，保存期间不误录。

下载 setup.exe 安装，或完整解压 portable.zip；source.zip 是源码。SHA256SUMS.txt 覆盖三个文件。二进制包包含固定 AutoHotkey 2.0.30、GPL 许可及对应完整上游源码。程序未签名。

验证：当前源码的 1539 项 AHK 无语音逻辑/布局检查和 8 项核心检查通过；本地安装包专用目录隔离安装/冒烟/卸载通过；CI 对标签重新构建测试。此前单机真实右 Shift 同键开关、XButton2 真关闭及手动 X 后重开已有证据，退出/安装完整隔离回归作为历史基线保留。本次未启用沙盒，不改用户系统设置。

限制：新版最终视觉截图验收未完成；实际 DPI 布局测量不等于全部字体和设备实测。曾发生一次登录后状态文件仍是旧 PID/Running=0，正常退出并启动一次恢复，但原因未查明；遇到该情况请先从托盘退出并确认进程消失，再升级或卸载。不能只凭进程存在或 --stop 返回 0 认定就绪/退出。没有宣称全部键鼠、全部 Windows 或录音状态专项验证。详见 docs/TESTING.md。
