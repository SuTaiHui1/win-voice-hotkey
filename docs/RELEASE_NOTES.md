# v0.1.4 · 中文听写保障与低内存待机

- 通过本程序唤醒前，明确请求并确认原目标编辑窗口的简体中文输入语言（zh-CN），避免因当前英文布局直接触发不支持语言。焦点/用户语言变化、缺少中文或切换超时会取消，不盲发Win+空格，不安装语言包或改变系统默认语言。
- 关闭后保留唤醒时切到的中文，不自动恢复旧英文。用户可自行切换语言；准备期间不抢焦点或覆盖主动选择。
- 中文准备的成功、准备中、失败和取消全部静默；保留真实内部状态/必要本地日志，不屏蔽Windows原生语音面板或全局系统通知。
- .NET/UI Automation代理按需启动。确认面板不存在、无活动请求/语言准备/打开过程且空闲约10秒后正常退出；无代理是合法待机。下一请求恢复，崩溃记录失败并在下次请求重试，不后台反复拉起。
- 保留默认XButton1打开/XButton2关闭、可配置同键开关、用户已保存绑定、自启、真实CloseButton.Invoke和正常退出协议。

单台Windows 11 x64、相同口径的约30秒样本：待机工作集合计约68→17 MB，私有提交约28→4 MB；代理存活的无输入夹具仍约67 MB工作集。首次代理就绪约251 ms、热查询约15 ms。251 ms不是Win+H面板完整弹出时间；数据不是跨设备承诺，不包含Windows语音服务，也不代表真实录音/识别负载。

本轮回归覆盖1539项绑定、60项中文静默保障、24项原子状态、27项空闲租约、8项面板核心、26项真实代理无输入生命周期及13项启动器检查；安装/便携包在隔离目录验证安装、升级、卸载和配置保留。完整明细见docs/TESTING.md及docs/TEST_RESULTS.json。真实物理侧键、面板开关及中文转写组合在本轮尚未经用户验收；未主动录音，不能把夹具结果写成完整听写通过。

升级：安装版运行新安装包到原项目安装目录；便携版正常退出后解压到新目录，只迁移自己的data/config.ini。升级保留个人绑定和自启，发行包不含个人配置、日志、机器路径或私有报告。

程序及安装包未签名；依赖Windows Win+H、麦克风权限、简体中文输入法及Windows在线语音输入所需网络。二进制已附固定AutoHotkey运行时、许可和对应上游源码，无需另装Python或AutoHotkey。Windows 10、ARM64、远程桌面、管理员应用、各类输入框、长期稳定性和完整设置视觉验收尚未全面验证。
