# v0.1.3 · 状态持久化与生命周期核验

- 完整状态快照以同目录原子替换写入并读回核验；主程序与代理均完成初始化才标记就绪，退出/失败保持同一实例身份。
- 默认有界生命周期日志记录启动、就绪、退出与状态发布错误，不记录输入历史、文本或音频。
- 启动、重复启动和停止核对实际进程、会话、窗口/实例标识；旧PID失效时定位本安装自己的实际实例。安装器复用停止核验。
- 驻留子进程不继承调用者输出管道，避免调用方等待管道关闭而挂起；查看状态保持只读。
- 自动回归覆盖1539项输入/设置、21项状态、8项面板核心及13项无输入生命周期检查；安装/便携包另做独立目录验证。

单台Windows 11 x64的完整重启/自然登录启动日志、状态快照及代理就绪已核实。此前旧状态报告已更正：检查端误读打包应用缓存副本，真实用户目录已正确记录新实例；不将其继续列为产品缺陷。

默认绑定仍为XButton1打开、XButton2关闭；同键切换和已有个人绑定继续支持。发行文件不含个人配置、日志、机器路径或私有诊断证据。安装/便携包包含固定AutoHotkey运行时、许可及对应上游源码。
