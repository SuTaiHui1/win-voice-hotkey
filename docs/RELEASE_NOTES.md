# v0.1.0 — Windows 语音输入快捷键工具

默认后退侧键打开 Win+H，前进侧键直接关闭系统语音输入面板，录音中无需先停麦。提供中文设置、独立录制、配置持久化与可选按用户自启。

普通用户下载 `*-setup.exe` 安装，或完整解压 `*-portable.zip` 后运行 `WinVoiceHotkey.exe`。无需开发环境。`*-source.zip` 是源码；包内 `third-party-sources` 包含所用 AutoHotkey 运行时的对应源码。

要求 Windows 11 x64、可用的 Win+H/麦克风/语音语言和 .NET Framework 4.x。Microsoft 的在线语音识别需要网络并遵循 Windows 隐私设置。本工具本身不录音、不读输入文本、不上传遥测。

本版启动程序、辅助程序、安装程序未签名。请核对仓库与 SHA256SUMS，不要关闭系统安全保护。Windows 更新改变面板结构可能影响关闭功能；状态菜单提供失败说明。

验证：本地发行草稿通过全局映射 142 项、鼠标映射 156 项、关闭绑定 132 项回归；空白配置/带空格路径、设置打开/关闭、配置重启、隔离自启和安装/卸载通过。自动测试未使用麦克风。真实关闭的历史单机用户验证不等同于本包跨设备测试；注销重登、自启全程、干净 VM、ARM64/Windows 10 均未验证。
