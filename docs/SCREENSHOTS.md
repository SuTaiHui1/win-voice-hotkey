# 设置窗口图片的来源

`images/settings.png` 是真实 Windows 原生设置窗口的自身渲染图，不是重画的界面或设计稿。

- 版本：v0.1.1。
- 使用与发行源码相同的 `KeySettings.ahk`、`KeyCatalog.ahk` 等运行文件，调用实际 `OpenKeySettings()` 创建设置窗口。
- 测试配置使用默认值：XButton1 打开、XButton2 关闭；没有加载用户现用配置。
- 通过项目已有的 `TestDesktop.cs` 在专用不可见桌面启动独立测试进程。没有切换用户桌面。
- 测试进程只向自己创建并拥有的设置窗口调用 Windows `PrintWindow`，将该窗口及真实子控件绘制到内存位图，再以系统 GDI+ 保存 PNG。保存前检查窗口 PID 与测试进程相同。
- 不读取桌面或其他窗口的像素，没有屏幕复制降级路径；不安装输入钩子、不启动语音识别、不访问麦克风，也没有捕获系统托盘、聊天或登录界面。
- 保存后目视检查文字、默认绑定及个人信息，并检查 PNG 不包含文本元数据。

不可见测试桌面的 Windows 主题、字体、边框与 DPI 可能不同于用户日常桌面；图片展示的是实际控件、文案和布局。没有重新绘制、润色或替换控件内容。

本次只补充文档图片，不修改现用安装、生产功能或 v0.1.1 二进制附件。实际语音操作的动态演示尚未录制。
