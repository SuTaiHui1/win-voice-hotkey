# 验证范围：0.1.2

## 本版自动检查

`scripts/Test.ps1 -UnitOnly` 从当前源码构建测试，在专用不可见测试桌面运行 AHK 回归，并运行 C# 面板核心纯检查。不会切换用户桌面、发送 Win+H、访问麦克风或调用实际 UIA 关闭。

AHK 检查覆盖可捕获键名与规范化、注入/重复/释放、修饰键组合保留、滚轮手势、设置暂停、同键状态查询与打开保护、配置保存回滚、候选缓存合并及扫描不完整拒绝。设置新增检查覆盖 Esc 安全出口、录制中保存不写配置/不弹模态、暂停时已排队动作不派发、原生退出控件边界与布局。

应用自身隐藏 GUI 测量 360×320、360×400、420×480、640×640、900×720 五种客户区，检查控件与布局一致、在界内且不重叠。本地测量 DPI=144（150%）；极小 360×320 时优先保证按钮可退出，录制区会缩小。矩形检查不能证明所有字体、换行和视觉效果正确。最新结果见 TEST_RESULTS.json；CI 产物中的 out/tests-*/results.json 记录该次真实成绩。

本次本地构建还通过专用目录的静默隔离安装、无钩子/无语音冒烟（设置打开/关闭、代理就绪、隔离自启快捷方式往返）及卸载；验证默认 XButton1/XButton2、保留配置和无关文件，日常程序及个人配置保持。这不是完整正常模式输入钩子回归。

## 已有真实交互和集成基线

本版功能来源的日常候选在单台 Windows 11 x64 主机上，用户确认右 Shift 同键打开/关闭、手动 X 关闭后重新打开；记录过 XButton2 调用真实 CloseButton.Invoke、面板隐藏和宿主仍存活。旧版本的录音中关闭有历史接受记录，不作为当前安装包全部录音情形的专项验证。原始日志含私人运行信息，不随公开仓库分发。

同一生命周期/安装器修复此前在隔离 Windows 环境通过 32 项退出/安装回归及 93 项安装停止门禁；测试包含无效令牌、超时、首次退出、升级/卸载拒绝和配置/无关文件保留。它们是历史基线，本次没有重新启用 Sandbox 重跑。`Test-Stop.ps1`、`Test-InstallerStop.ps1` 明确限制在该隔离环境运行，不能在日常主机绕过保护执行。

当前日常版设置更新曾正常退出并启动一次，状态和真实进程匹配，配置及入口保持；发布工作不再重启或改变该实例。发布版版本号和构建标记更新不构成新物理键鼠验收。

## 已知问题：登录后旧状态

曾在一次登录后看到新进程已启动，但 mapping-state.ini 仍是旧 PID/Running=0；原实例能处理正常退出，正常启动一次后新状态与代理就绪。已排查数据目录、文件一致性、基本 INI 读写和文件权限，尚未复现或确定更底层原因。**没有声称修复**。原登录实例完整就绪无法追溯；手动重启就绪不能替代登录自启验收。

若状态陈旧，先从托盘退出并核对进程消失，再重启、升级或卸载。停止命令对已不存在的记录 PID 返回 0，不能证明没有其他未记录实例；安装停止门禁也不能消除这个已知边界。
