## 中文原生机制的证据与未验证项

当前实现使用WM_INPUTLANGCHANGEREQUEST定向请求原焦点输入线程的zh-CN布局，再用GetKeyboardLayout确认；焦点、线程、用户语言变化时取消。此前同一原生语言实现已在独立安全文本框完成11项Windows真实语言切换检查，最终Win+H由测试回调替代。此历史候选证据不代表本正式包的完整听写验收。

**本轮未主动录音，也未完成真实物理侧键→系统面板→中文转写→关闭/重开的用户验收。** 真实CloseButton.Invoke、用户主动在语音面板打开期间切换语言、各类编辑控件/TSF实现、多窗口/管理员权限/DPI/远程桌面及长期听写稳定性不应标为全通过。夹具“panel present”“手动隐藏/状态变化”是状态逻辑验证，不能冒充真实Windows面板操作。

建议用户在独立文本框验收：中文与英文输入语言分别唤醒；空闲十余秒后的首次按键；短间隔关闭/重开；手动X关闭后再唤醒；准备期间切换焦点或主动语言。确认中文识别内容和关闭行为后再用于草稿。不自动录制声音或向聊天发送文本。

## 资源与响应实测口径

2026-10-25，一台Windows 11 x64、16逻辑处理器，约30秒合理空闲样本：

| 状态 | 自有进程工作集合计 | 私有提交合计 | 整机CPU平均/约1秒峰值 |
| --- | ---: | ---: | ---: |
| 原驻留代理日常待机 | 67.74 MB | 27.79 MB | 0.0612% / 0.2900% |
| 按需版本日常待机 | 17.06 MB | 3.85 MB | 0.0225% / 0.1939% |
| 代理存活无输入夹具 | 67.34 MB | 27.12 MB | 约0.06% / 0.2901% |
| 同夹具回收后 | 17.56 MB | 3.90 MB | 0.0161% / 0.0974% |

日常待机工作集减少约50.68 MB（75%）。MB=1,000,000 bytes；WorkingSet64为驻留页面，多个进程可能共享/重复计数；PrivateMemorySize64是私有提交，不能两者相减推导精确共享内存。CPU=自有进程用户+内核时间增量/墙钟/16×100；100%表示整机逻辑CPU容量，峰值为约一秒区间最大值。

首次真实代理就绪约251 ms，热presence查询端到端约15 ms，回收后再次就绪约246 ms；回收观察约10.5秒。冷启动包含进程/.NET/UIA预热，查询含夹具轮询时间。**不是面板完全出现、真实关闭Invoke或语音识别延迟。** 代理存活夹具用同口径计数，但主程序不装钩子且候选为空，不能视为实际听写活跃负载。Windows语音服务、TextInputHost和识别进程不计入本工具。短样本不构成跨设备、长期CPU/内存泄漏或录音负载保证。

原始私有测量报告、PID/机器路径及用户配置不会进入仓库或发行包；仅公开脱敏汇总。日常部署与发布源码功能一致，正式包只更新版本标识/安装标记和文档。公开包在隔离路径测试。发布回归发现的排队回复修复另在本机备份后正常重启本工具验证，保留日常绑定、自启和配置；未重启Windows。上述资源样本取自最终排队回复修复之前的相同按需生命周期实现，不作为修复后重新采集的负载数据。
