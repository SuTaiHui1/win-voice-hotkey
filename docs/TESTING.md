# 验证范围

## 历史基线

本地已部署 resident semantic close 版本的已保存验证记录显示：关闭键回归 132 项、全局按键回归 142 项、鼠标回归 156 项通过；真实系统语音面板的 7 次 CloseButton.Invoke 成功，用户确认流畅；程序重启后设置持久化已测。

这些是发布整理前的单机证据。原始记录包含个人运行信息，未随仓库分发。不将其当成本安装包或全部 Windows 版本的验证成绩。

## 本项目自动化

2026-10-16，本地发行草稿实际通过：全局映射 **142 项**、鼠标映射 **156 项**、独立关闭绑定 **132 项**；便携空白配置与已有配置重启、设置打开/关闭、隔离自启快捷方式往返、关闭辅助进程退出，以及隔离安装/运行/卸载通过。卸载保留配置和目标目录中额外加入的无关测试文件。脱敏结果见 [TEST_RESULTS.json](TEST_RESULTS.json)。

`scripts/Test.ps1` 使用发行包里的固定解释器，在独立目录运行三套真实源码回归：全局映射、鼠标映射、独立关闭绑定。测试用计数器替代 Win+H 与关闭动作，不调用麦克风或实际关闭系统面板。鼠标钩子安装/卸载测试使用专用测试桌面；不会接管用户当前桌面的输入。

完整模式还运行新目录/空白配置与带空格路径的便携启动，打开/关闭真实设置窗口、隔离自启快捷方式往返、退出状态落盘、已有配置重启、隔离安装/启动/退出/卸载与保留配置。`--smoke-test` 禁用全局输入钩子，以免影响正在使用的映射。辅助进程仍使用真实启动和清理流程。

测试结果写入 `out/tests-*/results.json`，以当前实际结果为准。CI 使用 `-UnitOnly`，不把后台运行器作为真实交互桌面验收。
