# 使用、安装与升级（0.1.4）

## 先确认系统语音输入

在一个独立空白文本框手动按 Win+H。Windows面板必须能正常工作，系统具备简体中文输入法、麦克风权限及在线语音输入所需网络。本工具不下载模型、不安装语言、不修改权限或默认语言。排查系统问题见 [Microsoft说明](https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc)。

## 操作

启动 WinVoiceHotkey.exe 后，默认 XButton1 打开、XButton2 关闭。在目标文本框中使用；设置里的打开/关闭可改成同一键，升级保留原绑定。打开前会对原焦点编辑窗口请求并确认zh-CN；成功、失败、准备中和取消均静默。切到的中文关闭后保留，不自动恢复英文。

准备期间改变窗口、焦点或语言可使本次唤醒取消，第二次同键操作也可取消尚未发送的打开；重新把光标放好后再按。已经打开的面板用关闭键或面板X关闭；关闭只调用确认目标的真实UIA CloseButton.Invoke，不用坐标、Alt+F4或终止系统服务。不同绑定时，关闭键不打开不存在的面板。

正常待机没有代理进程。需要时冷启动，面板关闭且持续空闲约10秒后回收；打开/关闭和语言确认期间不回收。首次请求可能比紧接着的热请求慢。

## 设置与状态

右键托盘→设置，或双击图标；也可运行 `WinVoiceHotkey.exe --settings`。录制只接收单键，鼠标录制需在专用区域；保存后应用，取消保留原值。设置时暂停映射。Esc先停止录制再取消，失焦/10秒超时停止录制。录制的是绑定键，不是麦克风音频。

右键托盘→查看状态会按需显示窗口；这是用户手动调用，不是自动中文通知。语言确认失败保持真实原因，静默不等于成功。自启在同一托盘菜单切换，默认关闭。

## 安装、升级与卸载

### 安装版

1. 下载同一Release的安装包和SHA256SUMS.txt，用 `Get-FileHash -Algorithm SHA256`核对。包未签名，不要求关闭系统防护。
2. 运行安装包，按当前用户安装。默认程序目录 `%LOCALAPPDATA%\Programs\WinVoiceHotkey`；配置/状态/日志在 `%APPDATA%\WinVoiceHotkey`。
3. 运行程序后设置按键；需要时启用托盘“开机启动”。不会自动启用Windows功能或重启电脑。
4. 升级运行新安装包并选择已有项目安装目录。安装器先验证和正常停止该安装的旧实例；失败/超时停止升级。自己的绑定和自启保持原值，不需要删除配置。
5. 卸载可用Windows已安装应用、开始菜单或安装目录Uninstall.exe。只处理带本项目标记的安装及清单文件，默认保留用户配置/日志和无关文件。确认不再需要后，可自行清理独立用户数据目录。

### 便携版

完整解压到可写目录，运行WinVoiceHotkey.exe；数据放在同目录data。不要在ZIP内启动。

升级时先正常退出旧版，解压新版到新目录，只迁移自己的 `data/config.ini`。不要复制mapping-state.ini、stop.request或close-broker临时文件，不要把安装版和便携版同时作为两个键位拥有者。若启用过便携版自启，移动/删除目录前取消旧入口，完成移动后重新启用。

卸载便携版：取消自启→托盘退出→确认本目录实例退出→删除该解压目录。是否保留自己的config.ini由用户决定。

## 正常停止与维护

`WinVoiceHotkey.exe --stop`验证本安装对应的实际进程、窗口/令牌及会话，正常退出后核实。验证失败返回2，超时返回3；请勿忽略退出码继续覆盖文件。不要结束Windows的TextInputHost或其他语音服务。

如需重置配置，先正常退出，再备份并移走自己的config.ini，随后启动创建默认配置。不要在程序运行时修改状态文件。故障详情见[TROUBLESHOOTING.md](TROUBLESHOOTING.md)。
